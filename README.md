# FlagForge

A production-ready Feature Flag SDK for React Native built with TypeScript.

## Features

- 🚀 React Native first
- 📦 Monorepo architecture
- 🔒 Fully typed
- ⚡ Lightweight
- 🧩 Pluggable storage providers
- 🌐 Remote configuration
- 🧪 Unit tested

## Packages

- @flagforge/core
- @flagforge/react-native
- @flagforge/storage
- @flagforge/network
- @flagforge/logger
- @flagforge/types
